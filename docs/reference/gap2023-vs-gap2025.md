# GAP2023 vs GAP2025 Differences

This document outlines the key differences between GAP2023 and GAP2025 scoring formulas.

## Overview

GAP2025 is an evolution of GAP2023 with refinements to leading coefficient calculation and some parameter adjustments. Both formulas share the same core structure.

## Summary of Changes

| Feature | GAP2023 | GAP2025 |
|---------|---------|---------|
| Leading Calculator | PWC2023 | PWC2023 (enhanced) |
| Altitude Bonus Factor | 0 | 0.05 |
| Leading Weight Factor | 1.0 (fixed) | Dynamic (0.8-1.2) |
| Time Decline | Flat (5/6) | Flat (5/6) |
| Arrival Points | Not used | Not used |

---

## Leading Coefficient Changes

### GAP2023

Uses PWC2023 leading calculator with fixed weight factor:

```typescript
// GAP2023 Leading Points
const leadingWeight = baseLeadingWeight * 1.0;  // Fixed factor
```

### GAP2025

Introduces dynamic leading weight based on speed section characteristics:

```typescript
// GAP2025 Dynamic Leading Weight
const ssRatio = speedSectionDistance / taskDistance;
const dynamicFactor = 0.8 + (0.4 * ssRatio);  // Range: 0.8 to 1.2

const leadingWeight = baseLeadingWeight * dynamicFactor;
```

**Rationale**: Tasks with longer speed sections relative to total task distance reward leading more heavily.

---

## Altitude Bonus in Leading Calculation

### GAP2023

No altitude bonus in leading coefficient:

```typescript
const altitudeBonusFactor = 0;
```

### GAP2025

Introduces altitude compensation:

```typescript
const altitudeBonusFactor = 0.05;  // 5% per 1000m above ESS

function getAltitudeBonus(altitude: number, essAltitude: number): number {
  const altDiff = altitude - essAltitude;
  return (altDiff / 1000) * 0.05;
}
```

**Effect**: Pilots flying higher receive a slight bonus in leading calculation, recognizing the tactical value of altitude.

### Weight Calculation Adjustment

```typescript
// GAP2023
function applyGap2023Adjustments(weights: PointWeights): PointWeights {
  // Fixed leading weight factor
  return weights;  // No adjustment needed
}

// GAP2025
function applyGap2025Adjustments(
  weights: PointWeights,
  task: TaskDefinition
): PointWeights {
  const adjusted = { ...weights };

  // Dynamic factor based on speed section ratio
  const ssRatio = task.speedSectionDistance / task.taskDistance;
  const dynamicFactor = 0.8 + (0.4 * ssRatio);

  adjusted.leadingWeight *= dynamicFactor;

  // Rebalance time weight
  const adjustment = weights.leadingWeight * (dynamicFactor - 1);
  adjusted.timeWeight -= adjustment;

  return adjusted;
}
```

## Impact on Scoring

### Leading Points Distribution

**GAP2023**: Leading points are distributed based purely on time spent leading relative to distance remaining.

**GAP2025**: Leading points consider:
1. Time spent leading
2. Distance remaining
3. Altitude advantage
4. Task structure (long SS = more leading weight)

### Typical Scenarios

#### Long Speed Section Task (SS = 80% of task)

| Formula | Leading Weight Multiplier |
|---------|---------------------------|
| GAP2023 | 1.0 |
| GAP2025 | 1.12 (0.8 + 0.4 × 0.8) |

**Effect**: GAP2025 rewards leading more heavily on classic racing tasks.

#### Short Speed Section Task (SS = 40% of task)

| Formula | Leading Weight Multiplier |
|---------|---------------------------|
| GAP2023 | 1.0 |
| GAP2025 | 0.96 (0.8 + 0.4 × 0.4) |

**Effect**: GAP2025 slightly reduces leading importance on tasks with long approach legs.

## Migration Considerations

### When to Use GAP2023

- Existing competitions mid-season
- Backwards compatibility requirements
- Simpler scoring verification

### When to Use GAP2025

- New competitions starting 2025+
- Events with varied task structures
- When altitude tactics should be rewarded

### Configuration for Compatibility

To run GAP2025 with GAP2023 behavior:

```typescript
const gap2025AsGap2023: ScoringFormulaConfig = {
  ...GAP2025_DEFAULTS,
  altitudeBonusFactor: 0,
  // Override dynamic weight calculation in scorer
};
```

## Validation Approach

When comparing results between formulas:

1. **Same Task, Both Formulas**: Run scoring with both and compare:
   - Day quality should be identical
   - Distance points should be identical
   - Time points should be identical
   - Leading points will differ

2. **Leading Points Comparison**:
   ```typescript
   const gap2023LeadingPts = pilot.leadingPoints_gap2023;
   const gap2025LeadingPts = pilot.leadingPoints_gap2025;

   // Difference should be proportional to:
   // - Dynamic weight factor
   // - Altitude bonus contribution
   ```

3. **Total Points Variance**:
   - Expect ±5% variance in leading points
   - Total points variance < 1% for most pilots
   - Larger variance for pilots with significant altitude advantage
